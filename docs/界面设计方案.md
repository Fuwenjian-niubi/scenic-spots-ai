# 景点讲解 AI · 界面设计方案

> 版本：v2.0 ｜ 状态：已实现（核心项落地，详见附录映射） ｜ 适用范围：`web/index.html` 重构
> 交付物：本方案 + 主界面线框 + 设置界面线框 + 开发验收清单

---

## 1. 目标与用户

### 1.1 产品定位
面向游客的实时景点讲解网页：选定景点 → 获取文字 + 语音讲解 → 追问细节 → 获取实用信息（门票 / 交通 / 开放时间）。

### 1.2 用户角色

| 角色 | 说明 | 核心诉求 |
|---|---|---|
| 游客（主要） | 游览前做功课 / 游览中边走边听 | 快速选中景点、听得懂、信息准 |
| 管理员（次要） | 部署与维护者 | 上传资料、配密钥、管理知识库 |

### 1.3 核心任务句
- **游客**：在游览前或游览中，需要 ≤ 2 步选定景点并获得准确、生动的讲解，因为要提升游览体验并获取实用信息。
- **管理员**：在首次部署时，需要上传景点文档并配置密钥，让讲解服务可用。

### 1.4 范围边界
- **本界面承担**：景点选择、文字/语音讲解、追问、来源引用、文档上传、密钥配置。
- **本界面不承担**：支付购票、地图导航（外链跳转即可）、多用户账号体系（当前为单机/局域网部署）。

## 2. 设计原则

| 原则 | 含义 | 落地要点 |
|---|---|---|
| **布局清晰** | 一眼看懂「我在哪、能干什么」 | 固定三区：顶部导航 / 左侧景点 / 右侧内容 + 操作 |
| **层级分明** | 信息按重要度分层，不堆砌 | 景点名称 > 讲解正文 > 实用信息 > 来源引用 |
| **视觉统一** | 颜色、字号、圆角、间距成体系 | 全部取自 §3 设计令牌，禁止散落魔法值 |
| **操作便捷** | 核心操作 ≤ 2 步可达 | 选中即讲、快捷提问、一键语音、键盘可完成发送 |

**优先级铁律**：决策必需信息 > 操作必需信息 > 解释辅助信息 > 低频扩展信息。首屏优先呈现「当前景点 + 讲解正文 + 主要操作」，而非数据库字段顺序。

## 5. 设置界面分类结构

**形态**：由「弹窗」升级为**右侧抽屉（Drawer，宽 480px）**，左侧分类导航 + 右侧内容，避免弹窗遮挡对话上下文。

| 分类 | 内容 | 对应现有实现 |
|---|---|---|
| **账号** | DeepSeek API Key、智谱 Embedding Key（输入 / 保存 / 清除 / 脱敏状态） | 原「API Key」tab |
| **通知** | 语音播报开关、语速（0.8–1.5）、音量 | 新增 |
| **外观** | 主题（浅色 / 深色 / 跟随系统）、正文字号（小 / 中 / 大） | 新增 |
| **隐私** | 清空对话记录、本地数据存储说明、清除本地缓存 | 新增 |
| **通用** | 文档 / 知识库管理（上传 / 列表 / 删除）、默认景点、关于 / 版本 | 原「文档管理」tab |

### 5.1 分类导航
- 抽屉左侧竖排分类项，图标 + 文字，当前项高亮。
- 窄屏（<768px）时分类导航收成顶部横滚 tab。

### 5.2 各分类字段规格

| 分类 | 字段 / 控件 | 默认值 | 校验 / 依赖 |
|---|---|---|---|
| 账号 | DeepSeek Key（password 输入 + 保存 + 清除） | 已配置则显示脱敏 | 空则禁用保存；保存成功回显脱敏 |
| 账号 | 智谱 Key（同上） | 同上 | 同上 |
| 通知 | 语音开关（Switch） | 关 | 关闭时隐藏语速/音量 |
| 通知 | 语速（Slider 0.8–1.5） | 1.0 | 实时预览 |
| 通知 | 音量（Slider 0–1） | 1.0 | 实时预览 |
| 外观 | 主题（Radio：浅色/深色/跟随系统） | 跟随系统 | 存 localStorage |
| 外观 | 字号（Radio：小/中/大） | 中 | 全局字号变量联动 |
| 隐私 | 清空对话（危险按钮） | — | 二次确认 |
| 隐私 | 清除本地缓存（危险按钮） | — | 二次确认 |
| 通用 | 上传区（拖拽/点击） | — | 格式 + 大小双重校验 |
| 通用 | 文档列表（类型/大小/时间 + 删除） | — | 删除二次确认 |
| 通用 | 默认景点（下拉） | 无 | 可选 |
| 通用 | 关于 / 版本 | — | 只读 |

## 6. 组件规格（关键组件字典）

### 6.1 按钮（Button）
| 状态 | 视觉 | 说明 |
|---|---|---|
| 默认 | 主色底白字 / 描边底 | — |
| hover | 亮度 -6%（描边钮边框变主色） | — |
| active | 亮度 -12% | — |
| focus-visible | 2px 主色外环 | 键盘可达 |
| disabled | 50% 透明度 + `not-allowed` 光标 | 文案用动词+结果 |
| loading | 内嵌 spinner + 禁用点击 | 防重复提交 |

按钮文案用「动词 + 结果」：`发送讲解`、`保存 Key`、`清除记录`、`删除文档`，不用裸「确定」。

### 6.2 输入框（Input）
- 默认 / focus（主色边框）/ error（红边框 + 下方错误文案）/ disabled。
- 错误文案与字段通过 `aria-describedby` 关联。

### 6.3 景点卡片（Spot Card）
- 默认 / hover（浅底）/ active（主色浅底 + 主色图标）。
- 收藏星标：点击切换，置顶排序。
- 卡片信息：首字图标 + 名称 + 一句话简介（单行省略）。

### 6.4 消息气泡（Message Bubble）
- AI：白底描边，左侧青色头像「AI」，流式时尾部光标闪烁，末附来源引用。
- 游客：主色底白字，右对齐。
- 每条 AI 消息提供「🔊 重播」「📋 复制」小操作（hover 显示）。

### 6.5 开关 / 滑杆（Switch / Slider）
- Switch：开=主色、关=灰；带可见焦点环。
- Slider：主色轨道，实时显示当前值，`input` 事件即时生效。

| 状态 | 触发 | 呈现 | 下一步 |
|---|---|---|---|
| 初始 / 欢迎态 | 首次进入、未选景点 | 欢迎语 + 引导文案 | 引导点击左侧景点 |

| 无权限 / 服务未启动 | 后端不可达 | 顶部全局横幅「服务未连接」+ 演示模式标识 | 按 README 启动 |

## 8. 交互细节

### 8.1 反馈提示（Toast）
- 位置：底部居中；类型：`success`（青）/ `error`（红）/ `info`（深灰）。
- 时长 2.6s，可手动关闭，多条时后出现覆盖前者。
- 仅承载轻量结果；破坏性结果用确认对话框（见 8.3）。

### 8.2 空状态
- 区分四种空态，解释与下一步完全不同：
  1. 首次使用（无景点）→ 引导上传文档
  2. 搜索无结果 → 建议换关键词
  3. 无文档 → 引导上传
  4. 加载失败 → 提供「重试」
- 每个空态含：图标 + 一句话原因 + 一个明确动作按钮。

### 8.3 错误处理
- **网络错误**：气泡内联提示 + 重试，不丢用户已输入内容。
- **表单校验**：字段级即时校验，错误信息与字段关联。
- **危险操作**（删除文档 / 清空记录 / 清除 Key）：二次确认弹窗，说明后果与是否可恢复；删除文档明确「同时从知识库移除」。
- **兜底**：后端不可达自动进「演示模式」，并全局横幅标识，避免用户误以为真实数据。

### 8.4 键盘与无障碍
- 全键盘可操作：Tab 顺序 = 导航 → 内容 → 操作；Enter 发送、Shift+Enter 换行、Esc 关闭抽屉/弹窗。
- 所有交互元素有可见焦点环（focus-visible）。
- 动态更新（流式讲解）通过 `aria-live="polite"` 通知读屏器，但避免逐字播报（节流）。
- 触控目标 ≥ 44×44px；文本对比度 ≥ 4.5:1；不只用颜色传达状态（辅以图标/文字）。

## 9. 响应式适配

### 9.1 断点
| 断点 | 宽度 | 布局 |
|---|---|---|
| 桌面 | ≥ 1024px | 三栏完整展示 |
| 平板 | 768–1023px | 侧栏收窄为图标栏（64px）或可折叠 |
| 手机 | < 768px | 侧栏变抽屉；内容单栏；操作区吸底 |

### 9.2 逐区块行为

| 区块 | ≥1024 | 768–1023 | <768 |
|---|---|---|---|
| 顶部导航 | 完整 | 完整 | 隐藏副标题；保留语音 + 设置 |
| 侧栏景点列表 | 240px 常驻 | 折叠为 64px 图标栏，悬停展开 | 汉堡键呼出全屏抽屉 |
| 景点详情卡片 | 横向 chips | 同左 | chips 换行 |
| 讲解对话流 | 内边距 20px | 同左 | 内边距 12px |
| 操作区 | 完整 chips + 输入框 | 同左 | chips 收进「+」或横滚；输入框吸底 |
| 设置抽屉 | 480px | 480px | 全屏（100vw） |

**表格类内容**（文档列表）在 <768px 时：文件项改纵向堆叠（图标 + 名称换行 + 大小时间缩略），删除按钮保留。

## 10. 可访问性要求

1. 语义化标签：`header / nav / main / aside / footer`，标题层级 H1 → H2 不跳级。
2. 图标按钮必须有 `aria-label`（如「打开设置」）。
3. 开关用 `role="switch"` + `aria-checked`。
4. 表单控件均有 `<label>` 关联；错误用 `aria-describedby` 关联。
5. 颜色对比度：正文 ≥ 4.5:1，大字号 ≥ 3:1。
6. 流式讲解区域 `aria-live="polite"`，更新节流。
7. 支持 `prefers-reduced-motion` 时关闭光标闪烁与过渡动画。
